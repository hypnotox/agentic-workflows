# Plan: Effort memory consensus and observation channel

## Goal

Implement ADR-0186: purpose-partition the effort memory skeleton into consumer-named sections
(`## Brief` with artifact pointers, an append-only ordinal `## Decision log`, a new
`## Observations` log, `## Handoff log`), wire the checkpoint backstop appends, give the logs
mechanical consumers (review-brief pasting plus the spine-level consensus-adherence check, and
the retrospective's primary-input read), and land the three declared claims with test backing.
Non-goals: no reviewer-spine lens dedup beyond this addition, no change to
reviewing-plan-resync's narrowed contract, no binary-side parsing or migration of memory files.

## Architecture summary

Five inline phases, each an independently green transaction. Phase 1 changes the skeleton's one
producer and its one detailed documentation home in the same commit (Go string, workflow-doc
template, and the tests pinning the old section literals). Phase 2 adds the checkpoint backstop
append to both checkpoint partials and updates the brainstorming skill's decision wording.
Phase 3 adds the consensus-adherence check to the shared review spine and the paste bullet to
the three full-review dispatching skills. Phase 4 rewires the retrospective template and its
local override in lockstep. Phase 5 is the direct Implemented transaction: authors the two new
claims and the one claim update with proof markers and a new consumer-coverage test, records
the changelog entry, and flips ADR-0186 and this plan to Implemented.

All work happens in the managed worktree checkout on branch
`awf/reshape-effort-memory-for-retrospective-value`. Every phase ends with `./x render`,
`awf check --staged`, and `./x gate` before its closing commit; rendered outputs (this repo's
`.claude/`, `.pi/`, `docs/`, and `examples/sundial/`) always travel with the template edit that
produced them.
