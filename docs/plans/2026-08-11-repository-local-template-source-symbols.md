# Plan: Repository-Local Template Source Symbols

## Goal

Emit deterministic, checked-in `awf:template-source` provenance across awf's configured Markdown outputs while keeping absent-config adopter bytes unchanged; do not attribute procedural Go producers or instrument native-format scripts and hooks.

## Architecture summary

Accept the reviewed ADR before implementation. Then replace flattened include text with a renderer-owned source-aware representation without changing output. Land marker emission and its first configured production consumer in one phase at the render assembly and project framing seams. The config package owns the repository fact and validation shape; the project package resolves it against working or staged repository state, selects declared Markdown producers, and projects it into artifact hashes. Complete producer parity and current-state authority before enabling the fact in awf's self-host config and regenerating the managed Markdown tree.
