---
title: Put bounded evidence before unbounded inventories in subagent returns
---
A subagent return can exceed the runtime's result limit even when its conclusion is concise. If a complete changed-path inventory appears before deviations, verification, or blockers, truncation can discard the evidence the parent needs to settle review and checkpoint authority.

Put bounded decision-bearing fields first: outcome, commit, deviations, failed or passed checks, and blockers. Summarize large inventories by count and category before any optional exhaustive list. The parent must independently inventory the checkout when a return truncates rather than infer that omitted deviations or checks were empty.
