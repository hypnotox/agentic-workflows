The tooling domain owns the command-line binary and local effort and worktree authority. An effort is one immutable slugged resident that always owns its working memory; efforts and managed worktrees are repository-local resident state at the primary control root, and no standalone memory resident exists. Managed worktree operations derive from native Git topology rather than stored evidence, so add, integrate, and remove restart from the actual topology they find; effort creation orchestrates the standalone add by default, with `--no-worktree` as the explicit exception. The binary alone manages durable coordination without Pi-session assignment. Audit cleanliness delegates repository, global, and system ignore semantics to read-only native Git porcelain rather than approximating them through go-git status traversal. The context query lives in `internal/contextq` behind the core's assembled `ContextState` seam: assembly, classification, projection, and result rendering move there, the core's exported surface carries no context result vocabulary, and the command binary keeps parsing, renderer selection, and exit mapping (ADR-0195).

`internal/commitmsg` owns Git cleaning and the reserved stale-ADR authorization trailer grammar. `internal/git` and `internal/snapshot` expose exact merge-head, parent, message, index, and committed-tree evidence. `internal/project` orchestrates the non-mutating live `commit-msg` decision and owns its actionable operation rendering. For historical audit, Project is only the outer composition point: `internal/audit` collects one range, owns its invocation-local revision cache, runs pure and live rules, replays the same authorization parser and incoming-parent qualification, and validates current-state transitions. Historical state derives only committed configuration and schema boundaries, ADR records and source bytes, and topic definitions and claims. Repository and staged checks retain full marker, coverage, and domain-sidecar validation. Code-only revisions reuse their immutable first-parent state, while `.awf` changes, changes under the parent's committed decisions directory, merge first-parent changes, and ambiguous evidence reload; a first parent outside the range loads directly as a cached boundary. Context cancellation and deadline expiry from any historical or live boundary abort the operation with matchable identity rather than becoming an advisory finding or permitting later audit work. A live refusal preserves the assembled merge for correction and retry.

The final bridge upgrade verifies its frozen version-1 attestation before its journal commits the replacement lock. Its historical routing payload is consumed as compatibility input and is not promoted.

The gated `check` family is organized by subject universe. `check repo` aggregates drift, state, prose, and memory checks; `check staged` aggregates HEAD-to-index state and rendered-output drift, while its commit-message child remains direct-only because it requires a message file. Bare `check` runs both aggregates, and disabled prose or memory children disclose their enablement knobs without failing.
