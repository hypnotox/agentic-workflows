The tooling domain owns the command-line binary and local effort and worktree authority. An effort is one immutable slugged resident that always owns its working memory; efforts and managed worktrees are repository-local resident state at the primary control root, and no standalone memory resident exists. Managed worktree operations derive from native Git topology rather than stored evidence, so add, integrate, and remove restart from the actual topology they find; effort creation orchestrates the standalone add by default, with `--no-worktree` as the explicit exception. The binary alone manages durable coordination without Pi-session assignment. Audit cleanliness delegates repository, global, and system ignore semantics to read-only native Git porcelain rather than approximating them through go-git status traversal. The context query lives in `internal/contextq` behind the core's assembled `ContextState` seam: assembly, classification, projection, and result rendering move there, the core's exported surface carries no context result vocabulary, and the command binary keeps parsing, renderer selection, and exit mapping (ADR-0195).

`internal/commitmsg` owns Git cleaning and the reserved stale-ADR authorization trailer grammar. `internal/git` and `internal/snapshot` expose the exact merge-head, parent, message, index, and committed-tree evidence, while `internal/project` orchestrates the non-mutating live `commit-msg` decision and owns its actionable operation rendering. A refusal preserves the assembled merge for correction and retry.

The final bridge upgrade verifies its frozen version-1 attestation before its journal commits the replacement lock. Its historical routing payload is consumed as compatibility input and is not promoted.
