The tooling domain owns the command-line binary and local effort and worktree authority. An effort is one immutable slugged resident that always owns its working memory; efforts and managed worktrees are repository-local resident state at the primary control root, and no standalone memory resident exists. Managed worktree operations derive from native Git topology rather than stored evidence, so add, integrate, and remove restart from the actual topology they find. The binary alone manages durable coordination without Pi-session assignment. Audit cleanliness delegates repository, global, and system ignore semantics to read-only native Git porcelain rather than approximating them through go-git status traversal.
