Configuration is strict tracked authority under `.awf/`. The journaled upgrade boundary validates and publishes migrations atomically with lock replacement as the commit point. The live schema exposes one standard footprint, retains only repository-fact configuration, and rejects retired profiles, workflow selectors, and removed variables. `integrationBranch` explicitly names the branch that receives completed managed-worktree efforts. Rendering configuration remains separate from local effort and worktree residents.

Frozen migrations preserve supported historical inputs without reintroducing their retired fields into live configuration. Current schema migrations remove recognized obsolete workflow metadata, preserve historical decision and effort bytes unless a migration explicitly owns them, and refuse ambiguous or meaningful retired overrides rather than silently discarding them.
